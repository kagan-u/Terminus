## 1.3 (2026-09-22)

- version system: mini, basic, standard, deep, wide, mega, ultra, god

  - terminus_config.py: comparison table + optimal finder
  - presets.json: shared configuration presets
- terminus_build.py: live build simulation (simulated and real modes)
- terminus_tui.py: curses interactive terminal interface
- terminus_benchmark.py: build/read/compression benchmarks
- terminus_hash.py: integrity verification + manifest generation
- terminus_banner.py: ASCII banner generator
- Makefile: unified command entry point
- docs: CONTRIBUTING.md, ROADMAP.md
- removed: web apps, static site, Netlify, GitHub Pages deploy
